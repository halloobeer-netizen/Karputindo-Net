# Karputindo.net

**Customer Management & Mapping Platform for Internet Service Operations**

Karputindo.net is a full-stack customer management platform designed to centralize operational data for an internet service provider. The system combines customer records, service-package management, Excel-based data import, administrative workflows, operational reporting, and interactive customer mapping in one responsive dashboard.

## Highlights

- Customer database management
- Customer status tracking and operational summary
- Interactive customer map with location data
- Internet package management
- Excel data import workflow
- Administrative dashboard and reporting
- Responsive desktop and mobile interface
- Authentication and protected administrative access

## Engineering Focus

This project demonstrates the development of a production-oriented business application that connects user interface design, application logic, database workflows, authentication, spatial visualization, and deployment-ready architecture.

## Tech Stack

- **Framework:** Next.js 16, React 19, TypeScript
- **Database / ORM:** Prisma 6
- **UI:** Tailwind CSS, Radix UI, Lucide React
- **Mapping:** Leaflet, React Leaflet
- **Data:** XLSX / Excel import, TanStack Table
- **State & Validation:** Zustand, Zod, React Hook Form
- **Authentication:** NextAuth
- **Visualization:** Recharts

## Core Modules

### Customer Management
Manage customer records, service status, contact information, packages, and operational data from a centralized interface.

### Customer Mapping
Visualize customers with coordinate data on an interactive map and quickly navigate between customer records and geographic locations.

### Data Import
Import customer datasets from Excel to reduce repetitive manual entry and accelerate migration of existing operational data.

### Operational Dashboard
Monitor total customers, active customers, installation processes, cancellations, coordinate coverage, and recent growth from a single dashboard.

## Product Direction

Karputindo.net is built as a practical digital operations platform for customer-centric internet service businesses, with a focus on structured data, fast administration, and location-aware workflows.
